Zadání

Úvod

  • Na stránce katalogu národních otevřených dat je mimo spousty jiných datových sad možné stáhnout i seznam zastávek s rámci Pražské integrované dopravy ve formátu JSON.
  • Původní zdroj je na adrese http://data.pid.cz/stops/json/stops.json. Pokus o jeho přímé stažení vám ale selže na CORS, které jsme detailně neprobírali. V kombinaci se snahou zbytečně nevytěžovat veřejné API a zajištěním stability testů, je kopie těchto dat uložena lokálně ve složce data a v hw-08-helper.js je funkce, která zprostřednuje jejich "stažení" a simuluje prodlevu, která by reálně nastala při stahování přes internet. Tuto funkci vracející Promise můžete použít takto: window.fetchStopsData()
  • Dokumentaci těchto dat naleznete na stránce PID opendata.

Načítání dat

  • Na stránce je připravené tlačítko Načíst data o zastávkách, které zatím nic nedělá. Pomocí JS zajistěte, aby kliknutí na něj stáhlo data o zastávkách pomocí funkce fetchStopsData.
  • Pomocí atributu disabled zajistěte, aby na tlačítko nešlo kliknout znovu, pokud právě probíhá načítání dat.
  • Pokud už jsou data načtena, změňte text tlačítka na Aktualizovat data o zastávkách.

Vyhledávací pole a tlačítko

  • Jakmile jsou data načtena, zobrazte:
    • text "Hledat",
    • textové pole s id searchInput,
    • a tlačítko "Hledej!", s id searchButton.
  • Tlačítko "Hledej!" bude neaktivní vždy, když bude hledací políčko prázdné.
  • Hledání je možné kromě tlačítka vyvolat také klávesou enter (přes event keyup) - pokud je políčko nevyplněné, ani stisk enteru neprovádí žádnou akci.

Výsledky hledání

  • Hledání probíhá nad staženými daty, vyhledává se v atributu name u každé zastávky, hledá se přesná shoda textu (nenormalizujte háčkyčárky ani velká písmena), hledaný text se ale může nacházet kdekoliv (i uprostřed) názvu zastávky.
  • Výsledek hledání se vypisuje do divu s id results a může být tří typů:
    • Pokud není nalezena žádná shoda:
      • Vypíše se informace Žádné výsledky!
    • Pokud je nalezena právě jedna shoda (stačí jednoznačnost hledání, nemusí být zadán celý název zastávky):
      • Zobrazí se detail této zastávky, viz níže.
    • Pokud je nalezeno více shod:
      • Zobrazí se text Měli jste na mysli:
      • Zobrazí se seznam výsledků, uživatel může kliknout na libovolný výsledek (použijte <a> element), poté se zobrazí detail této zastávky, viz níže.

Zobrazení detailu zastávky

  • Jako nadpis se vypíše name zastávky.
  • Zastávka má více nástupišť. Pro každé nástupiště vypište:
    • Nástupiště platform, kde platform je načteno z dat o nástupišti. Pokud nástupiště nemá označení, nevypisujte nic (pouze Nástupiště)
    • Tento text bude odkazovat na Google mapy, se zadanými souřadnicemi konkrétného nástupiště, viz Tipy závěrem.
    • Dále bude zobrazen seznam linek, které z tohoto nástupiště odjíždí, každý řádek bude složen ze čtyř částí oddělených mezerou:
      • typ dopravního prostředku (nepřekládejte, použijte typ přímo z dat),
      • číslo linky,
      • ➔
      • cílová stanice.
